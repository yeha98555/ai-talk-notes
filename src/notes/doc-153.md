---
title: First Steps Toward Automated AI Research
speaker: Richard Socher, Recursive AI
video: https://youtu.be/pWXUkLP9uWM
---
The talk sets out a decades-long ambition: a "Eureka machine" that automates scientific discovery itself, and frames the recent breakthrough in AI-driven research automation as the first small proof points toward it. The starting lens is evolution — biological evolution over 3.5 billion years, then technological evolution compounding over millennia into exponential (and eventually S-curved) growth in economic output and population, and finally the evolution of scientific theories themselves, which Karl Popper described as competing explanations subjected to empirical natural selection. The throughline is that more science produces more technology, which produces more growth and more human flourishing — so scaling scientific discovery should be treated as a central lever for the next era of progress.

The problem is that science itself doesn't scale by adding people: as fields fracture into ever-narrower subfields, fewer researchers work on each one, a limit noted decades ago by Stanisław Lem. This motivates the Eureka machine — an attempt to automate discovery across physics, chemistry, biology, neuroscience, medicine, economics, and astrophysics. It rests on four pillars: cataloguing existing human knowledge, ingesting scientific measurement data, building simulations for anything that can't yet be measured (since anything simulatable can be verified and optimized by AI), and, as a last resort, physical industrial labs for real-world experiments — all coordinated by a swarm of agents. Because so much of AI's own infrastructure (web search, browsers, GPUs) was originally built for humans, there's a broader opportunity to rebuild each layer specifically as tooling for a future superintelligence — an approach already being pursued for LLM-native web search.

On how to build such a machine, the argument draws a direct analogy to NLP's own history: progress came each time a manual, hand-engineered process (linguist-built features, hand-designed architectures) was replaced by a learned one. The same logic implies the Eureka machine should be built by having AI improve itself — a form of recursive self-improvement (RSI) that has only become feasible in the last six to eight months, now that models can code reliably over long time horizons, giving a system enough self-awareness of its own shortcomings to actually revise itself. True RSI is distinguished from a weaker, more common pattern: using an AI research system to improve some *other*, separate model or process (as with small NanoChat runs) is useful but not the same as a system with full access to its own pretraining, RL, and harness that updates itself end-to-end.

Three concrete proof points illustrate the weaker form working today. On NanoChat, a small-model bits-per-byte benchmark the community had pushed to 0.93, the system ran for about a day and reached 0.91, discovering genuinely novel mechanisms (hash bigram/trigram embedding tables mixed into attention value paths via learned gates) rather than just tuning hyperparameters. On the NanoGPT speed-run benchmark, it beat over a year of combined human-and-AI effort, shaving more than two seconds off a ~70-second run. On CUDA kernel optimization — an area where even large, expensive MoE training clusters often run at only ~30% utilization — the system, without any dedicated kernel experts on the team, beat the best entries on Nvidia's own benchmark leaderboard across categories; results were validated jointly with Nvidia to rule out reward hacking.

The closing argument is that intelligence isn't a single scalar but spans roughly ten distinct dimensions or "spaces," and current systems remain astronomically far from the upper bounds of nearly all of them — so there's little reason to expect the current growth curve to flatten soon. The talk ends as an open invitation to collaborate on building this system.
