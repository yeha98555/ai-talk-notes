---
title: 架構現代 AI 系統：平台、代理人與整合
speaker: Frédéric（MIA）、Shao（Bell Canada）、Allan（BUZZ HPC）— 座談會
---
這場座談由三位實務工作者組成——分別來自加拿大應用型 AI 研究機構、Bell Canada，以及主權級 GPU 雲端服務商 BUZZ HPC——並以他們剛與 Bell 及 Kids Help Phone 合辦的心理健康黑客松作為切入點，討論現代代理式（agentic）系統究竟該如何建構：平台該扛下哪些責任、團隊又該自己掌握哪些部分，以及從黑客松展示品到正式上線之間真正的落差在哪裡。這場黑客松本身——超過 100 個團隊打造護欄機制，判斷對話式代理人何時該將對話升級交給真人——透過講者們在 BUZZ 的 HPC 基礎設施上以 Kubernetes 打造的自助式評測與排行榜系統，一週內收到近千次提交；賽程中途還特意加入一組隱藏資料集，用來抓出過度擬合排行榜的隊伍。

座談中反覆出現的主題是 token 經濟與掌控權：從前沿實驗室取得 API key 快速做出原型很容易，但需要規模化、資料留在境內、或行為可預測的團隊，最終會想自行架設開源模型。BUZZ 將自己定位為消除這道技術門檻的基礎設施——提供 GPU、執行推論引擎（vLLM、SGLang、TensorRT-LLM）、支援縮放到零再快速拉起，並讓任何 coding-agent 工具（Claude Code、Codex、Cursor、Open Code）都能改接開源模型而非封閉模型。具體動機包括避免「用量五分鐘就燒光額度、之後被收取十倍 token 費用」這種零資料保留政策下的成本結構，以及取回輸出的多樣性與可調控性——例如套用 LoRA、steering vectors 等研究技巧。

硬體經濟學也是重點：GPU 世代（如 Blackwell 對 FP4 量化模型的效率優勢）與 GPU 容量（如 A100 較大的 VRAM 仍能跑某些 Blackwell 推論卡跑不動的模型）之間存在權衡；講者也指出近期 GPU 租金因供給緊縮而大幅上漲（H100 約每小時 2.5 美元、H200 約 3.5 美元、A40 約 0.5 美元，且已難以租到 2 美元以下的 A100）。經驗法則是：不確定能否完成、或必須拿到最佳輸出的任務用最強模型，例行性「粗活」則用較小模型即可；本地可跑的 27B–35B 模型侷限明顯，但 200B 到上兆參數等級、需要高階 GPU 的開源模型，已能在彈性與成本上與封閉旗艦模型競爭。

封閉 API 另一個痛點是掌控權旁落：供應商可能悄悄以量化或降規版本置換模型而不告知，或無預警升級模型導致既有 prompt 與測試全數失效；相較之下，自行架設並凍結版本的開源模型能提供更高的可預測性與可重現性。

從黑客松到正式上線之間的落差被形容為「80% 很快，95% 很難」：快速做出原型並不難，但要達到可上線水準，需要扎實的評測、迭代與使用者回饋。過度依賴 LLM-as-judge 只是把問題往後推——誰來評判這個評判者？因此仍需人工評測、真正貼近業務需求（如同產品經理的思維），必要時甚至投入高規格的人工標註以取得黃金標準資料，並結合 RLHF 做客製化。座談也提到 RL gym、可驗證獎勵（如結合 Lean 證明檢查器解出 Erdős 問題）與世界模型，是訓練更穩健代理人的下一個前沿。

三位講者也分享了各自的 agentic 技術棧。Bell 的作法分三層：面向非技術員工的企業級通用 LLM／輕量 RAG 平台；直接啟用既有企業軟體內建的代理式功能（摩擦最低、投報率最高，也呼應目前「先把已付費的工具用好用滿」而非急著再買新 SaaS 的心態）；以及在雲端上針對特定業務需求打造的客製化生產系統。Frédéric 強調技術棧演進極快（從提示工程到 RAG、工具、記憶、MCP、harness 一路疊加），刻意不讓自己被綁在任何特定技術棧上，主張「今天先交付價值，但要清楚知道未來的退場路徑」。Allan 的落差則在於缺乏透過受限／結構化生成（constrained/structured generation）取得的掌控力——用文法限制解碼來強制輸出格式或強制工具呼叫順序；封閉模型供應商基於安全與對齊考量不開放這項能力（因為前綴注入可能繞過安全機制），而 BUZZ 因信任客戶而提供，這種「確定性流程 + LLM 自由發揮」的混合設計，正是深度研究（deep research）類代理人能大幅超越預設 coding agent 的關鍵。

治理與可觀測性被視為企業級部署的必要條件：代理人應獲得不亞於（雖不必完全等同於）一般員工的監督層級；需要限制代理人能觸及的資源與資料庫、對 MCP 工具加一層包裝以防止不可逆操作；業界已有代理人刪除資料庫、或對 Jira 發出上萬次請求等真實事故，凸顯流程紀律與工具本身同樣重要。

在驗證代理人產出方面，講者建議建立 QA-agent 技能：對 PR 自動截圖、點擊介面、再截圖比對並產出通過或失敗報告；也可用雲端模擬環境在合併前測試。但根本上仍是既有的軟體工程紀律：先定義清楚需求與架構，讓代理人互相審查與自我檢討，並且要把生成程式碼與其實際視覺／UX 結果的落差閉環起來——因為 LLM 擅長理解文字型程式碼，卻未必能直覺對應 CSS 會呈現出什麼畫面。可觀測性工具方面，講者提到 AgentOps 與 Arize Phoenix 等基於 OpenTelemetry 的方案能記錄工具呼叫與 MCP 軌跡，但當紀錄量達到數億 token 時，人工或 LLM 輔助排查成本很高，因此建議先用啟發式（非 AI）方法過濾，並且把重點放在「預防失敗」（例如限制不可逆操作）而非僅僅「偵測失敗」。

座談也提醒：沙盒雖然重要，卻不是萬無一失的防線——隨著模型在程式碼生成上越來越強，業界普遍反映沙盒相當脆弱，即便像 Nvidia 的相關代理人專案，很大程度上也只是在做「更好的沙盒」而已，因此沙盒更像是延緩而非杜絕逃逸風險。最後，BUZZ 也公佈了目前的 GPU 租金行情（H100 約每小時 2.5 美元、H200 約 3.5 美元、A40 約 0.5 美元、暫無 A100，長租或大量承諾可議價，Blackwell 需另洽），呼應了前面關於硬體成本急遽上漲的討論。
