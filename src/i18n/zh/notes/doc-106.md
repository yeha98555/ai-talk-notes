---
title: 影片沒有記憶——我們如何為它打造一個
speaker: James Le, TwelveLabs
---
這場演講從一個挑釁性的觀點切入：儘管影片本質上是對過去的保存，但大多數影片 AI 系統其實在系統意義上並沒有記憶。核心論點是：不應把影片當成一堆影格（frames）的集合——也就是一疊圖片加上或許一份逐字稿——因為這樣會丟失讓影片真正有意義的連續性。更好的心智模型是把影片視為一個「時空體」（spatial-temporal volume），其中包含視覺內容、語音、聲音、動作、OCR、鏡頭切換、場景轉換、中繼資料與時間，而真正困難的問題在於如何保存這個時空體內部的關係，讓應用程式能在數百萬個片段（甚至橫跨 PB 級素材）中進行遍歷。

把影片硬塞進以文字為主的技術堆疊會產生三種失敗模式。第一是「錯誤的脈絡」：對影格取樣或擷取逐字稿後丟進提示詞，會破壞真正定義事件的時空關係。第二是「錯誤的記憶」：文字系統對記憶的理解（檢索、向量搜尋、更大的上下文視窗）無法捕捉影片所需的持久連續性——例如將今天的場景與另一個檔案、集數、鏡頭角度、季別甚至年份中發生的事連結起來。第三是「薄弱的推理」：以文字為先的系統無法自然地對動作與因果關係進行推理，因此永遠無法建立誰出現、發生了什麼、以及發生了什麼變化的持久結構。

影片有五個特性說明了這件事有多困難：時間性（意義取決於前後脈絡，單一影格可能造成誤導）、多模態（單靠逐字稿會漏掉商標，單靠影格會漏掉口說的主張）、密度高（短短幾分鐘就包含數十個鏡頭與主張，訊號分布不均）、模糊性（人物與地點會在不同光線、角度或部分可見的情況下重複出現，概念的意義是隨時間累積而非在單一時刻出現）、以及查證成本高（企業工作流程需要將主張精確追溯回原始片段）。

TwelveLabs 的技術堆疊分層處理這些問題：語意分塊（semantic chunks）捕捉有意義的時間單位；多模態嵌入編碼器（Marengo）將這些片段轉換成時空向量嵌入；時空脈絡儲存庫（context store）保存可重複使用的結構，如時刻、實體與中繼資料；具備影片脈絡感知能力的語言模型（Pegasus）則作為推理層，負責摘要、中繼資料整合與比較——這一切都以 API 形式對外開放。

一個關鍵區別是「搜尋」與「記憶」的不同。搜尋能從龐大的影片庫中找出相關片段，但只回傳候選結果，不具連續性。記憶則能在整個語料庫中保存實體、時間軸與證據，讓應用從「找出類似這樣的東西」轉變為「告訴我這個影片集合知道什麼」——回傳的是結構化知識與時間軸，而非單一片段。這種記憶需要沿兩個維度擴展：時間維度（在不重新處理整個檔案庫的情況下對數年的素材進行推理，透過可重複使用的表示法支援多跳、情節式回想且低延遲）；以及空間維度（融合來自多個攝影機角度、串流或密錄器的證據，形成一個統一且即時的理解）。

演講提出的表示法是「脈絡圖」（context graph）：一個持久且可查詢的結構，連結影片時刻、實體、出現位置、關係、時間戳記、中繼資料與語料庫層級的脈絡。最底層是有時間邊界的「時刻」（證據單元），往上是「出現」（實體何時何地出現），接著是「實體」（人物、品牌、地點、概念），再來是「關係」（共同出現、跨時間與地點的序列），最頂層則是語料庫層級的脈絡（主題、模式、覆蓋範圍缺口）。不同的問題會遍歷圖中不同的部分——簡單搜尋直接命中時刻，實體導向的工作流程從一個人物展開延伸到其出現紀錄，而敘事性問題則會沿著關係跨時間追蹤。

由此衍生出五項設計原則：一次性攝入、多次推理，把理解的成本一次付清而非每次查詢都重新計算；儲存「原始單元」而非只儲存答案，讓時刻、實體、出現紀錄能支援下游的搜尋、剪輯與分析；為每一項主張建立依據，將證據對應到來源影片中的精確時間戳記；讓「意圖」形塑記憶，因為同一份素材在品牌安全、合規審查或創作者分析中需要不同的原始單元，記憶層必須是可配置的；以及保持該層的可組合性、以 API 為優先設計，讓應用程式能接入結構化、有評級的中繼資料。

圍繞「影片工作者」（video worker）打造的框架（相對於一次產生單一答案、無狀態的靜態模型）意味著系統應支援：記憶、任務規劃（判斷是搜尋、摘要還是多步推理）、檢索正確證據、專家工具（縮放、影格比對、中繼資料強化）、操作邊界（對時間、成本、範圍、自主程度的明確限制）、輸出契約（自然語言 vs. 附帶引用與時間戳記的結構化資料），以及評估檢索、綜合與預算遵循是否正確。

三個示範案例展示了這套方法，使用的是 TwelveLabs 的代理產品 Jockey：體育理解方面，攝入 67 支世界盃影片，找出「差點進球」的鏡頭並解釋為何未進球、描述進球的建構過程並辨識傳球者與射門者、並能在整個語料庫中追蹤單一球員（如梅西）並描述鏡頭運鏡；安防監控方面，對公開的監視器素材進行車輛與行人計數與分類、偵測安全事件（如險些相撞、闖紅燈），並在雨天或曼谷擁擠場景等不同條件下依然有效；廣告分析方面，對一支五分鐘的 Adidas 世界盃廣告進行分析，分類出適合置入廣告的時刻——揭露鏡頭、硬切、高潮能量節拍、商標出現位置等，對於選擇品牌內容置入時機的廣告主極具價值。

演講最後將此定位為「影片認知基礎設施」，而非應用層：以知識儲存庫作為記憶層、以可配置的攝入流程決定擷取內容、以語料庫摘要提供整個影片庫層級的理解、並透過解析／搜尋／回應 API 對外提供服務——目標應用涵蓋媒體檔案庫、內容創作者、體育分析與廣告等工作流程，目前處於私人測試階段。
