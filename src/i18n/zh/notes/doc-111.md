---
title: Active Graph 代理執行環境（BabyAGI 4）
speaker: Yohei Nakajima, Untapped Capital
---
這場演講介紹 ActiveGraph，一個實驗性的開源代理執行環境（runtime），源自三年、九次 BabyAGI 迭代的經驗，以及先前 Instagraph、Mindgraph 等圖形化專案。出發點是：長時間運行的代理容易崩潰，而研究主題一直是打造「最簡單、卻能自我改進」的系統。

多數代理架構是圍繞 LLM 建構：先接上 response API，再加工具、記憶，最後才補上日誌記錄。ActiveGraph 反其道而行，改為圍繞「日誌」建構。這裡指的不是代理做的每件事，而是代理發生的每一次「變化」——提示詞、事實、任務——全部被記錄成單一、不可變、具型別的事件日誌，作為唯一的真實來源。這份日誌會投射出一張圖，代表代理目前的狀態。行為（behaviors）是對圖變化做出反應並發出新事件的單元，事件更新狀態後又可能觸發新的行為；關鍵是 LLM 彼此之間不會直接對話——所有溝通都必須經過這個共享狀態，此架構明確借鑑 1970、80 年代的黑板系統（blackboard architecture）與 Kafka 式的微工作者模式。政策（policies）則規範圖如何被修改：某些變更（例如加入一則研究來源）可以自由進行，其他變更（修改主提示詞、更動可能與既有事實矛盾的內容）則需要人工核准或自動化的矛盾檢測。把所有事情都導向單一事件日誌的好處，是原生支援重播（replay）、回溯（rollback）與分支（fork）——ActiveGraph 被定位為執行環境而非固定框架，常見的代理架構（例如 ReAct 迴圈）都能用同樣的行為／事件模式在其上重建。

情境管理透過「views」處理——本質上是把相關子圖抽取出來、餵給某個行為的圖形查詢——而代理則由模組化的「packs」組裝而成（核心、工具、密鑰、記憶、身分、通訊、對話等 pack），每個 pack 綁定物件結構、工具、行為與各自的政策，因此可以直接替換記憶 pack 而不動到代理其他部分。

多項實驗驗證了這套方法。把日誌本身當作記憶使用——嵌入查詢、擷取相關日誌訊息及其結構化前後文，不做額外的事實或實體抽取——在 LongMemEval 上表現不錯，顯示記憶資料與日誌資料本質上高度重疊。一個意外發現的實務優勢是：某次基準測試中途 API 金鑰用完，ActiveGraph 直接從上次完成的問題繼續，而非重跑整個流程，這與過去建構的代理經驗截然不同。請程式碼代理（例如 Replit）在 ActiveGraph 之上建構程式碼代理或深度研究代理時，不需額外開發，就自動獲得完整可稽核的事件日誌與證據圖——這是執行環境本身的副產品，而非刻意設計出來的。

名為 Regimes 的專案探索了受控的自我修改：代理先在 LongMemEval 上將自身的失敗類型分類，只被允許修改對應的部分，提出修補方案後，經過靜態檢查與沙盒檢查，再於保留測試集上驗證後才被接受。經過多輪迴圈，只有少數修補被採納，但在 LongMemEval 分數上取得了輕微卻具統計顯著性的提升——更重要的是，系統保留了哪些方法「沒有」奏效的紀錄，而不只是成功的部分。以此為基礎延伸出的 ActiveGraph Lab，是一個自我指涉的研究代理，會讀取專案自身所有的部落格文章與程式碼，提出新實驗、徵求執行許可、撰寫實驗結果，並已經在自身程式碼中發現並修復一個錯誤（透過合併的 PR），也自行發現並記錄了「pack 可跨儲存庫移植」這件事。

另一項測試利用 Kaggle 上一個決定性（非 LLM）寶可夢集換式卡牌牌組競賽，以 Elo 式對戰計分。經過約 80 次迭代，一個看似隨意的調整請求（例如加入能量卡）會促使代理對戰數百場模擬對局，只有在勝率提升且達到一定統計信心（Wilson 分數門檻）時才接受變更；80 次提案中約有 20 到 30 次被採納，分數逐步提升，同時代理清楚保留了哪些先前實驗失敗及其原因的紀錄。

反覆出現的驚喜是：AI 編碼助理在撰寫這種去耦合、黑板式的架構時，明顯比手寫代理迴圈更得心應手——推測是因為訓練資料中累積了數十年關於黑板／Kafka 式系統的討論，遠多於僅有數年歷史的 LLM 代理模式資料；除錯方式自然而然從閱讀對話日誌，轉為直接查詢 ActiveGraph 資料庫，因為一切都已經乾淨且具型別地被記錄下來；此外，pack 能在不同儲存庫間乾淨載入，無需額外整合工作。

最後提出的假設是：長時間運行的代理不只需要預測性的世界模型（先驗），還需要一種「經驗性的世界模型」——類比海馬迴維持一種類似不可變事件日誌的機制，投射出狀態，並透過重播與鞏固過程週期性地回饋到先驗中。與其認為代理的能力會隨模型變強而收斂成純粹的推理，不如說身分與能力可能需要源自代理自身累積的經驗日誌，就如同人類的行為較少取決於純粹的推理能力，而更多來自實際的生活經驗——這也意味著隨模型變強，「框架」（harness）並不會就此消失。
