---
title: 資料品質是運算力的乘數
speaker: Ari Morcos, DatologyAI
---
這場演講從運算稀缺的前提出發：H100 價格已從低點回升約 40%，推理模型的 token 用量約為非推理模型的八倍，且預估未來一年還會再增加五倍，而前沿實驗室已開始限制推論資源（Google 限制了 Meta 對 Gemini 的用量，OpenAI 開始銷售「token 期貨」）。在運算存取本身可能受限的世界裡，講者主張資料品質正是能把固定運算預算轉化為更多模型能力的槓桿——它讓學習曲線變得更陡峭，使同樣的資料／運算／時間／金錢預算能產生遠遠更好的表現，或用小得多的預算就能達到相同表現。

背後的核心目標是最大化模型每看到一個 token 所獲得的邊際資訊量。這需要與任務相關的資料（沒有放諸四海皆準的最佳資料集——法律應用需要法律資料而非醫療資料）、多樣性（缺乏多樣性正是模型脆弱、換個問法就答錯的根源），以及跨眾多異質來源的正確混合比例。

DatologyAI 將自己定位為「資料的煉油廠」：不生產新的 token，而是把既有的公開、專有與授權 token 升級，透過四個階段——清理（啟發式過濾、依低 n-gram 門檻對下游評測做基準去污染以對抗 benchmaxing）、篩選（品質分類器、主題分類與平衡、去除語意冗餘、依品質與相關性做上下採樣、任務分佈匹配）、創造（透過合成改寫擴充資料規模與多樣性，因內容仍源自真實文件而不會產生模型崩潰），以及組合（在如今標準的多階段訓練課程中排序與混合資料集）。

實驗結果橫跨多個領域。在視覺語言模型上，對約 250 億 token 的 Mammoth 資料集（用於訓練融合適配層）做篩選，使表現大幅超越由 Qwen3、InternVL 等公開 VLM 所定義的帕雷托前沿——單靠篩選就帶來 14 個百分點的絕對提升，並以約少 145 倍的訓練運算量逼近 Qwen3.5-4B 的表現，經篩選訓練的模型回答也明顯更精簡（以每次推論 flops 計算，效率優勢依然成立）。在多語言文本模型上，僅用 8% 的多語言 token（每種語言最多約 60 億 token），篩選後的表現仍以約少 8 倍的運算量超越 Qwen／Liquid／Cohere 所定義的前沿；篩選英文資料被證實能提升非英文表現，反之亦然,呈現跨語言遷移效應，其遷移幅度與該語言和英文的相似程度相關。一個以一兆 token 訓練的篩選過密集 Llama 式模型的縮放曲線，能準確預測某客戶以約多 50 倍運算量訓練的稀疏模型（RC 的 Trendy Large）的表現,顯示只要正確篩選資料並模擬 token 稀缺性,便能可預測地外推到更大規模,在啟動旗艦訓練前大幅降低風險。

在合成資料方面，「改寫」做法將真實文件轉換成數百種模板格式（例如把一篇企業併購文件改寫成是非題）。由於內容根植於來源文件，不會出現模型崩潰問題，且改寫模型只需完成較簡單的轉換任務，而不必真正教會模型理解底層概念——但改寫哪些文件至關重要：改寫高品質文件而非隨機文件,才能帶來真正的提升。

兩個客戶案例展示了各訓練階段之間的協同效應。與 Thomson Reuters 合作時，在一個開源模型上以 1000 億筛選過的 token（混合其專有法律資料與近似預訓練分佈的公開資料，運算量不到預訓練預算的 1%）進行中期訓練，使 legal-bench 表現提升約五個百分點，且未出現災難性遺忘——更關鍵的是，將 Thomson Reuters 既有的後訓練框架套用到這個中期訓練過的模型上，其後訓練帶來的增益幾乎是套用到預設指令微調模型的三倍，原因是模型起始策略已經更準確。與 RC 的 Trendy Large 合作時,一個完全開源、美國製造、以 17 兆 token 訓練的模型完全使用篩選過的公開資料（無專有資料、無閉源模型蒸餾），表現可與 GLM-5 及 Kimi 匹敵，在部分任務上甚至超越 Claude——而 RC 團隊在去年年中之前從未訓練過模型，卻能連同其他幾個模型一起，以總計不到 2000 萬美元的成本完成，挑戰了「打造具前沿競爭力的客製化模型需要數億美元」的普遍假設。

結語強調：優先追求每個 token 的資訊量而非單純堆疊 token 數量,重複展示高品質資料通常勝過加入低品質資料，並應把資料篩選視為一個前沿研究工程問題——沿多個維度為資料評分，並將這種評分能力擴展到 PB 級規模——因為資料品質仍是當今最被低估的運算力乘數。
